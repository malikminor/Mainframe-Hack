# Mainframe Hack

A 2D platformer game built with Python and the Arcade library.

## About
You play as a rogue digital virus infiltrating a cybernetic system. 
Your goal is to steal data from a cache deep inside the system and 
return it to the USB entry point to complete a "heist." Survive as 
long as you can as the system fights back.

## Built With
- Python 3
- [Arcade](https://api.arcade.academy/) (`pip install arcade`)

## How to Run
1. Install the dependency: pip install arcade
2. Run the game: python Mainframe_Hack.py

## Controls
| Action     | Key                        |
|------------|----------------------------|
| Move Left  | A or Left Arrow            |
| Move Right | D or Right Arrow           |
| Jump       | W, Up Arrow, or Space      |

## Gameplay
- Navigate from the USB port, steal data caches, and return them
- Each successful heist increases the difficulty
- Enemy speed, spawn positions, and patrol patterns are randomized
- Features coyote time jumping for smoother platforming
